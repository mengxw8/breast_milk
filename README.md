# 吨吨吨

一款用 Flutter 编写的母乳库存管理应用。按袋记录入库时间、奶量、储存方式和食物备注，生成带二维码的标签，并通过扫码完成整袋出库。应用还提供期限提示、库存统计、每日提醒和本地数据备份。

> 当前主要面向 Android 开发。仓库包含 Flutter 生成的其他平台目录，但蓝牙标签打印、备份文件选择等功能使用 Android 原生实现，其他平台尚未完成适配与验证。

## 功能

| 模块 | 功能 |
| --- | --- |
| 首页 | 查看可用库存袋数与奶量、最早到期记录，以及优先使用列表 |
| 入库 | 设置入库时间、奶量、冷冻或冷藏方式、常用食物标签和备注；预览期限与标签；可选择保存并打印或仅保存 |
| 标签打印 | 连接已配对的蓝牙打印机，打印 40 × 30 mm TSPL 标签；标签包含二维码、编号、时间、奶量、储存方式和食物信息；支持测试打印与重复打印 |
| 库存 | 按状态筛选、按编号或备注搜索；查看记录详情与状态时间线；开始解冻、整袋出库、撤销出库、标记丢弃或删除记录 |
| 扫码 | 扫描标签二维码或手动输入编号，确认整袋出库；过期记录会提示并阻止正常出库 |
| 统计 | 查看库存分类汇总、最近一周每天的入库与出库奶量，以及未来 30 天的期限记录 |
| 设置 | 管理常用食物标签、蓝牙打印机、每日到期提醒时间，以及 JSON 数据导入和导出 |

打印失败时，已保存的入库记录仍会保留；可以重试打印或稍后从库存中重复打印。

## 开始使用

### 环境要求

- Flutter 稳定版，且包含 Dart **3.13.2 或更高版本**（以 [pubspec.yaml](pubspec.yaml) 的 SDK 约束为准）。
- Android SDK，以及能运行当前 Flutter Android 工程的 Android Studio / Gradle 环境。Android 构建配置使用 Java 17。
- 一台 Android 设备用于相机扫码与蓝牙打印的真机验证。
- 如需打印：支持项目当前标签指令的蓝牙标签打印机。现有界面和标签尺寸按 **Xprinter P203A、40 × 30 mm** 设计；其他型号需自行验证兼容性。

安装 Flutter 和 Android 开发环境后，先运行 flutter doctor 检查配置。随后在仓库根目录执行：

~~~bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
~~~

项目使用 Drift 生成数据库代码。修改数据库表或相关生成模型后，需要重新执行 build_runner。已有生成文件位于 lib/data/database/app_database.g.dart。

构建 Android 调试安装包：

~~~bash
flutter build apk --debug
~~~

调试 APK 通常生成在 build/app/outputs/flutter-apk/app-debug.apk。当前 Android 的 release 构建仍使用调试签名配置；正式分发前请配置自己的发布签名。

### 首次使用流程

1. 在系统蓝牙设置中配对打印机，然后打开应用的「设置 → 蓝牙打印机」，授予蓝牙权限、连接设备并打印测试标签。只记录库存时可以跳过打印机配置。
2. 在首页点击「母乳入库」，填写入库时间、奶量、储存方式以及可选的食物标签和备注。
3. 选择「保存并打印标签」或「仅保存，稍后打印」。把打印好的标签贴到对应奶袋。
4. 使用「库存」查看记录和期限；取用时进入「扫码」扫描二维码，也可以手动输入编号。
5. 在「设置」中按需开启每日提醒，并定期导出备份。

首次使用相机、蓝牙和通知功能时，Android 可能请求相应权限。Android 12 及以上的蓝牙扫描和连接需要蓝牙权限；较早版本的蓝牙扫描使用定位权限。

## 期限规则与状态

当前期限计算由 [expiry_policy.dart](lib/domain/services/expiry_policy.dart) 实现：

| 储存方式或操作 | 应用内计算规则 |
| --- | --- |
| 冷冻 | 入库后 **6 个自然月**为最佳使用时间，**12 个自然月**为最终期限；分别提前 1 个月进入提醒阶段 |
| 冷藏 | 入库后 **96 小时**为最终期限 |
| 开始解冻 | 从开始解冻时起 **24 小时**为最终期限 |

冷冻月份按入库时的本地日期计算；如果目标月份没有对应日期，则使用该月最后一天。记录会在冷冻在库、冷藏在库、解冻中、已出库、已过期、已丢弃等状态间流转。出库按**整袋**处理，不记录部分取用量。

这些时间是应用使用的管理规则，不会测量奶袋温度或卫生条件。实际保存与使用仍应结合采集、储存和解冻条件及专业建议判断。

## 数据与备份

- 业务数据保存在设备应用目录内的 SQLite 数据库（breast_milk.sqlite），由 Drift 管理。仓库代码没有提供账号登录或云同步。
- 「设置 → 导出数据」生成 UTF-8 JSON，包含母乳记录、状态事件、食物标签及其关联。
- 「设置 → 导入数据」从文件选择器读取 JSON 并与本机数据合并；本机独有记录不会因为导入而删除。导入前应用还会保存一份本地快照。
- **提醒开关和提醒时间等应用设置不在上述 JSON 导出内容中。**
- 备份可能包含入库时间、饮食备注等个人信息。请自行选择可信的保存位置，不要将真实备份或数据库文件提交到公开仓库。

## 项目结构

~~~text
lib/
├── app/                 # 启动、路由、导航与主题
├── data/                # Drift 数据库和仓储实现
├── domain/              # 记录模型、状态机、期限与统计规则
├── features/            # 首页、入库、库存、扫码、统计与设置页面
├── platform/printer/    # Flutter 侧打印接口与 MethodChannel 桥接
└── shared/              # 通用组件
android/app/src/main/kotlin/
└── cn/mengxw/breast_milk/
    ├── printer/          # 蓝牙连接、TSPL 打印和原生通道
    └── backup/           # Android 备份文件通道
test/                    # 领域规则、仓储、页面和平台桥接测试
~~~

主要技术：Flutter / Dart、Riverpod、go_router、Drift / SQLite、mobile_scanner、flutter_local_notifications，以及 Android Kotlin 原生通道。Android 打印实现依赖仓库内的第三方 printer-lib-3.5.8.aar。

## 开发与验证

在仓库根目录运行：

~~~bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
~~~

自动化测试覆盖部分业务规则与界面行为。蓝牙连接、打印标签位置、扫码相机权限和通知表现仍需在目标 Android 设备上验证。
